# Dynamic Web Applications: Express Project

This project demonstrates the use of [Express.js](https://expressjs.com/) to build dynamic web applications.

## Features

- RESTful routing
- Middleware integration
- Static file serving
- Basic error handling

## Getting Started

1. Clone the repository.
2. Install dependencies:
    ```bash
    npm install
    ```
3. Start the server:
    ```bash
    node index.js
    ```
4. Visit `http://localhost:8000` in your browser.

## Routes

- `/` - Home page (simple greeting)
- `/about` - About page
- `/contact` - Contact page
- `/date` - Displays live-updating current time
- `/welcome/:username` - Personalized welcome message
- `/a` - The "a" page :D

## Requirements

- Node.js (v14+)
- npm
